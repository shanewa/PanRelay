# 度盘接力存（PanRelay）隐私说明

最后更新：2025-10-07

本说明适用于浏览器扩展「度盘接力存」（以下简称「本扩展」）。上架 Chrome 网上应用店、Microsoft Edge 加载项时，可将本页公开 URL 填作隐私政策链接（例如 GitHub 仓库中的 `docs/PRIVACY.md` 对应页面）。

## 我们收集哪些数据

本扩展**不设自有后端服务器**，不向作者服务器上传你的百度网盘账号、密码或文件列表。

仅在浏览器内使用 **`chrome.storage.sync`（或等价存储 API）** 保存下列**本地配置**，用于记住你的设置（可能随浏览器账号在已登录 Chrome/Edge 的设备间同步，由浏览器厂商政策决定）：

- 是否已完成公众号解锁（布尔值）
- 接力转存开关、每批文件数、转存间隔、是否始终走接力等偏好
- 视频倍速开关、倍速数值、是否保持音调等偏好
- 是否显示 AI 视频笔记「下载MD」按钮

点击「下载MD」时，扩展在当前页面内读取你正在查看的图文笔记，转换成 Markdown 后直接由浏览器下载到本地；笔记内容**不会**上传或保存到扩展存储。

解锁码在扩展内**本地校验**通过后写入上述存储；**不会**把解锁码或百度登录凭证发送到我们的服务器（我们也没有用于接收这些数据的服务器）。

## 百度网盘与 Cookie

- 你需要**自行在浏览器中登录** [百度网盘](https://pan.baidu.com)。本扩展**不**模拟登录、**不**读取或填写登录表单中的账号密码、**不**将百度账号密码存入扩展存储。
- 当你在分享页点击「保存到网盘」并启用接力转存时，扩展在页面上下文中发起与百度网页端相同的接口请求（如 `/share/transfer`），请求会携带**当前浏览器中已有的百度网盘 Cookie**（`credentials: 'include'`），与你在未安装扩展时打开同一网页的行为一致。
- 本扩展**仅处理你当前打开的公开分享链接**及你在该页勾选的文件/文件夹，**不会**扫描或上传你的整个网盘目录。

## 网站访问范围

本扩展仅在以下域名注入脚本并请求网络：

- `https://pan.baidu.com/*`
- `https://yun.baidu.com/*`

未申请访问其他网站的权限。

## 微信公众号解锁

本扩展免费使用。关注微信公众号仅用于获取解锁码与向作者反馈问题；二维码图片打包在扩展内。关注行为发生在微信客户端，由微信平台处理；本扩展**不**收集你的微信 OpenID 或手机号到我们的服务器。

## 第三方分析与追踪

本扩展**不包含**广告、统计分析 SDK 或跨站追踪代码。

## 数据删除

你可以在浏览器扩展管理页**移除本扩展**，或在扩展弹窗中清除同步存储（卸载扩展即删除本地扩展数据）。百度网盘账号与 Cookie 由你自行在浏览器或百度账号设置中管理。

## 儿童隐私

本扩展不面向 13 岁以下儿童主动收集个人信息。

## 变更与联系

我们可能更新本说明；重大变更会在仓库中更新日期。使用本扩展即表示你理解并同意本说明。

使用本扩展转存或播放内容时，请遵守百度网盘用户协议及当地法律法规。因使用频率、百度侧风控等导致的账号限制，本扩展不提供保证。
