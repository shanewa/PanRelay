## 简短说明（manifest / 商店摘要，约 132 字内）

百度网盘分享页：用户点击「保存到网盘」后可分批接力转存；播放页可选视频倍速，AI 视频笔记可一键下载为 Markdown。需自行登录百度，无后端，不收集百度密码。

## 详细说明（商店「详细描述」草稿）

**度盘接力存**是一款面向百度网盘用户的免费浏览器扩展，纯前端运行，**没有自有服务器**。

**接力转存（分享页）**

- 仅在 `pan.baidu.com` / `yun.baidu.com` 的**分享链接页面**工作。
- 你在页面中勾选文件、选择「保存到」目录后，**点击「保存到网盘」**才会执行；不会在后台静默批量转存。
- 当选中内容较多或包含文件夹时，扩展按与网页相同的接口**分批**转存，并可在弹窗中调节**批次大小与请求间隔**，以降低超时或请求过快的情况。
- 未安装扩展时，百度网页自身的保存流程不受影响；小批量选中仍可走官方保存。

**视频倍速**

- 仅在百度网盘 / 云盘**网页内**对预览、播放中的 `video` / `audio` 调节播放速度。
- 在扩展弹窗中开启并设置倍速；不面向全网所有网站。

**AI 视频笔记下载 Markdown**

- 在百度网盘播放页的「图文笔记」工具栏中，「分享」后面增加「下载MD」按钮。
- 点击后把 AI 生成的图文笔记整理为 Markdown 文件保存到本地，文件名以当前视频名开头，便于归档到笔记软件。
- 笔记内容在浏览器本地转换，**不**上传到任何服务器；可在弹窗中关闭此按钮。

**账号与隐私**

- 请先在浏览器中**手动登录**百度网盘；扩展**不**保存百度账号密码。
- 转存请求使用浏览器已有的登录状态（Cookie），数据**不经过**扩展作者的服务器。
- 详见 [隐私说明](PRIVACY.md)。

**免费与解锁**

- 扩展完全免费。首次使用需关注公众号获取解锁码（用于本地解锁，便于用户联系作者反馈问题），**不**出售百度网盘服务。

使用请遵守百度网盘用户协议及相关法律。

## 单一用途（Single purpose）表述建议

帮助用户在百度网盘分享页完成由本人触发的分批转存，并在同站网页播放时可选调节视频倍速、把 AI 视频笔记下载为 Markdown。

## 权限说明（审核问卷）

| 权限 | 用途 |
|------|------|
| `storage` | 保存用户设置与解锁状态 |
| `host_permissions`: `pan.baidu.com`, `yun.baidu.com` | 仅在百度网盘域名注入分享页转存、播放页倍速与笔记导出脚本，并调用同源转存接口 |

未申请 `tabs`、`cookies`、`webRequest`、`<all_urls>` 等 broad 权限。
